# Surround Sound Studio

A PS5 homebrew app for home-theatre sound, with two pages (switch with **L1 / R1**; the tabs at the top show where you are):

- **Passthrough**: plays test clips as an HDMI bitstream, so your receiver decodes them.
- **Speaker Lab**: EVO Player's speaker tests, 3D sound field and DualSense microphone calibration, on plain 8-channel PCM.

## Passthrough

The Passthrough page sends **Dolby Digital, Dolby Digital Plus (including Atmos), DTS, AAC, DTS-HD, and Linear PCM** over HDMI untouched, so your soundbar or AV receiver does the decoding. It's built on [ps5-homebrew-ui](https://github.com/blackbearreloaded/ps5-homebrew-ui) and doubles as a hardware test: every number the console returns is on screen.

It runs as an ordinary sandboxed app. It doesn't need a sandbox escape or any kernel access.

## What works (PS5 Pro, firmware 12.70, 2026-10-08)

| Clip | Format | Console mode | Result |
|---|---|---|---|
| `aac-5.1.aac` | AAC 5.1 (ADTS) | 1, 48 kHz | plays, receiver decodes |
| `ac3-5.1-448k.ac3` | Dolby Digital 5.1 | 0, 48 kHz | plays, receiver decodes |
| `dts-5.1-768k.dts` | DTS 5.1 (core) | 2, 48 kHz | plays, receiver decodes |
| `dtshd-5.1.dtshd` | DTS-HD 5.1 | 4, 192 kHz | sent as DTS-HD (receiver result pending) |
| `truehd-5.1.thd` | Dolby TrueHD 5.1 | Sys 5, 768 kHz | plays; the receiver shows "Dolby Audio" |
| `eac3-5.1-640k.eac3` | Dolby Digital Plus 5.1 | 3, 192 kHz | plays, receiver decodes |
| `pcm-2.0.wav` | Linear PCM Stereo | 5, 48 kHz | plays uncompressed |
| `pcm-5.1.wav` | Linear PCM 5.1 Surround | 6, 48 kHz | plays uncompressed |
| `local-atmos.eac3` (yours, not shipped) | Dolby Digital Plus (Atmos) | 3, 192 kHz | plays (displays ATMOS badge) |

The bundled clips are royalty-free channel-ID tones generated by `../tools/make-clips.sh`. Each speaker beeps in turn (front left, front right, centre, subwoofer, surround left, surround right), so a wrong channel map is easy to hear.

### Using the Passthrough page

| Button | Action |
|---|---|
| D-pad | pick a clip |
| ✕ | play it as a bitstream |
| ○ | stop |
| □ | loop on/off |
| △ | read the receiver's format list again (after switching inputs, for example) |

The right side shows what your TV or receiver says it can decode (read over HDMI), and the live result: the port handle, the switch's return code, bursts sent, errors and time.

While a bitstream plays, the console mutes all other sound from the app, including the menu sounds. That's how the PS5 handles bitstream mode, not a bug.

## Speaker Lab

Ported from EVO Player's Surround Sound Studio (#106). It opens one 8-channel PCM port and offers:

| Item | What it does |
|---|---|
| 3D Sound Field | music that follows a sound source you fly around the room; the speakers' levels come from distance-based amplitude panning |
| Auto Calibration (Mic) | measures every speaker through the DualSense microphone at your seat: level, extra distance and the delay that would line it up. A report: nothing is changed on the console |
| Spatial Orb (Free Roam) | move the source yourself and play a tone on the nearest speaker |
| 360 Rotation Sweep | the source circles the room once |
| Auto Test 5.1 / 7.1 | a tone on each speaker in turn |
| Speaker Layout | switch between 5.1 and 7.1 |
| Silence | stop everything |

Press D-pad right to walk the speakers on the stage and ✕ to test one. On the orb, the left stick or D-pad moves the source, **L2 / R2** change its height (L1 / R1 switch pages here), △ cycles Manual / Orbit / Flyby, □ recentres it.

Calibration needs `libSceAudioIn`, which the payload SDK has no stub for; the Makefile builds one from `stubs/libSceAudioIn.c`.

Switching pages stops the other page's audio: bitstream mode would mute the speaker tests.

## Building

The build needs Linux or WSL with clang 18, or any Docker image with the PS5 toolchain (EVO Player's `evo-player/ps5-dev` image works). From this folder:

```bash
make init TITLE_ID=PPSA99051 APP_NAME="Surround Sound Studio"   # already done; change the ID if it clashes
make ffpfsc                                              # -> dist/PPSA99051.ffpfsc
```

With Docker on Windows:

```bash
MSYS_NO_PATHCONV=1 docker run --rm -v "<path>/sample-app:/w" -w /w evo-player/ps5-dev:llvm18-sdk-v0.42 make ffpfsc
```

The first build downloads the pinned PS5 payload SDK into `.deps/`. **On Windows, clone with `core.autocrlf=false`.** With CRLF line endings, the runtime checksum check fails ("runtime checksum manifest does not match the release digest").

Install: copy `dist/PPSA99051.ffpfsc` to `/data/homebrew/` on the console (FTP) and start it from the home screen (ShadowMount+). Close the app before replacing the file.

### Adding your own clips

Put elementary-stream and audio files (`.ac3`, `.eac3`, `.dts`, `.dtshd`, `.aac`, `.thd`, `.wav`) in `assets/clips/` and list them in `index.txt`. The console can't list folders under `/app0`, so the index is required. Clips cut from files you don't own go in `local-*` names and `index.local.txt`, which git ignores:

```bash
ATMOS_SOURCE="some Atmos file.mp4" ../tools/make-clips.sh   # cuts local-atmos.eac3
```

## Where the code is

| File | What it does |
|---|---|
| `src/passthrough/iec61937.cpp` | finds frames in AC-3, E-AC-3, DTS, ADTS AAC, Dolby TrueHD, DTS-HD, and WAV streams and wraps them in IEC 61937 bursts or PCM chunks. Plain C++, no PS5 calls. |
| `src/platform/ps5/bitstream_out.cpp` | the console side: `sceAudioOutExOpen` / `sceAudioOutOpen` → `sceAudioOutExConfigureOutput` → `sceAudioOutOutput` → close → restore; and the receiver's format list |
| `src/passthrough/bitstream.hpp` | the small interface between the two, so the screen also builds for the PC preview (`host/bitstream_host.cpp` pretends) |
| `src/concepts/passthrough.cpp` | the screen |

To add passthrough to your own app, copy the first two files. You need nothing else from the kit.

Two traps found on the way:

- **Link the functions; don't look them up.** `sceKernelDlsym` is refused in a sandboxed app. The SDK's `libSceAudioOut` stub already exports `sceAudioOutExOpen`, `sceAudioOutExClose`, `sceAudioOutExConfigureOutput` and `sceAudioOutSysGetHdmiMonitorInfo`, so just declare them `extern "C"`.
- The kit's `save::read_file(path, &data, max)` fails on any file bigger than `max`. It's a size limit, not a read length.

The app logs to `/mnt/sandbox/PPSA99051_000/download0/hui/dev/app.log`, readable over FTP while it runs. Lines start with `[PT]`.
